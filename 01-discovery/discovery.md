## Week 1 - Initial Discovery
## 1. Facts
· There are laptops, cameras, projectors and specialist equipment that can be booked.
· System is going to be used by student and staff members.
· System uses mixture of booking ways.
· System is not automated.
· Equipment may not be returned on time.
## 2. Assumptions
· How much equipment?
· Staff review report.
· Booking time Frame.
· Booking rules for staff / students type equipment.
## 3. Unknowns
· Is mixture of bookings connected to each other?
· Is there any reminder with deadline of returning?
· Is there ease to contact staff in order to book item?
· Is one user can book multiple items?
## 4. Stakeholders
· Student - Aviability, easy booking.
· Staff - Equipment, automated system.
· Developer - Redevelop system.
· Tester - Debug system.
· Suppliers.
## 5. Goals
· System must help students book items clearly without double-booking. The system needs to show aviability.
· Make a united system.
· Make staff not spending their time by filtering bookings.
· Make an email notification few days before deadline.
## 6. Scope
· Students may not see an email notification.
· Student could not finish booking an item, so we need to have an expiry session to avoid booking without confirmation.
·  
## 7. Candidate Requirements
###Functional
· The system should allow authorised users to view equipment availability.
· The system should allow authorised users to request/book available equipment.
· The system should prevent conflicting bookings for the same equipment.
· The system should provide users with information about who to contact for support.
##Non-functional
· Security: Only authorised users should be able to make or manage bookings.
· Users should be able to understand how to check availability and make a booking without unnecessary difficulty.
## 8. Requirement Surgery
· Just before entrance the system should verify user by Google Authenticator in order to keep system secure.
· The system shall only allow authenticated and authorised users to create, modify or cancel bookings.
